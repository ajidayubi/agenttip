How it works

  1. You type an Agent ID name, e.g. ajidayubi.
  2. The contract looks the name up on-chain in the Agent ID registry (SPACE ID, BNB Chain) and finds the owner's wallet address.
  3. Your BNB is forwarded in full to that address. The contract keeps nothing and has no owner or admin functions.

Tips are irreversible. Check the resolved address before you send — the tip goes directly to whoever owns that name.
